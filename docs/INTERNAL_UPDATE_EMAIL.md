**Subject:** Custodia dashboard update — login required + new features

Hi team,

We’ve deployed updates to Custodia. Here’s what’s new and what you need to know.

**Important: dashboard access now requires login**

- The dashboard and all tracking data are behind login.
- You’ll need to sign in with your email and password to access the dashboard.
- For testing, you can use the shared admin account below (please use only for internal testing).

**Shared admin account (internal testing only)**  
- **URL:** [your-dashboard-url, e.g. https://custodia.world/pages/dashboard]  
- **Email:** admin@custodia.world  
- **Password:** admin123  

**Sign up (new users)**

- New users can create an account at **Sign up** (link on the login page).
- They enter name, email, and password (min 8 characters) and are assigned to the default company; they can then log in and access the dashboard for that company.

**Other updates**

- **Repeaters on the map:** Repeater locations appear on the map with icons; you can toggle “Repeater coverage” in Filters to show or hide 7 km coverage circles.
- **Header:** Dashboard header is updated: logo on the left, location count and download/refresh in the centre, your email and logout on the right.
- **Forgot password:** If you forget your password, use “Forgot password?” on the login page; you’ll receive a reset link by email (or see it in server logs if test mode is on).
- **Data access:** After login, you only see data for your company; the system uses your account to scope trackers and locations.

If you run into any issues or need a dedicated account, let me know.
